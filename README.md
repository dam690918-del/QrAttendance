QR Attendance («Кьюар Посещаемость») (Android)
Учебный проект на Kotlin для учёта посещаемости занятий в колледже по динамическому QR-коду.

Основные функции
Три роли: студент, преподаватель, администратор.
Преподаватель запускает пару и показывает QR-код, который обновляется каждые 20 секунд.
Студент отмечается, отсканировав код камерой телефона.
Привязка аккаунта студента к одному телефону.
Заявки на регистрацию и управление пользователями и предметами у администратора.
Хранение данных в облаке (Firebase Firestore).
